# When Will Your Part of the World Cross 2°C?

DSC 106 Project 3 interactive visualization, built with D3.js.

- `index.html`, `style.css`, `main.js`: the visualization
- `data/`: output of `DSC106_P3_CMIP6_Checkpoint.ipynb`

To view locally, run `python3 -m http.server` in this folder, then open http://localhost:8000.
